# Student's Daily View ("Day View")

## 1. Daily Page Structure
The screen dedicated to a specific day (e.g., Wednesday) is split into two core sections:

* **Today's Main Schedule:** A sequential list of lessons assigned for the current day (numbered starting from 1 onwards).
    * **Visual Status Indicators:** Lessons display real-time status markers (e.g., completed or submitted lessons are highlighted in blue, while active, in-progress lessons remain clearly distinguishable).
* **Backlog Section ("Tails"):** Positioned directly beneath the main daily schedule so the student encounters them daily without cluttering the current day's primary workflow.
    * Displays uncompleted tasks from previous days with explicit origin labeling (e.g., *Mon #4* and *Tue #2*).
