# Lesson Screen Structure (Wizard / Step-by-Step Interface)

The individual lesson page is structured as a multi-step **Wizard**, guiding the student sequentially through the learning material:

## 1. Main Content Pages (Step-by-Step Wizard)
* **Header:** Displays the lesson title prominently at the top of the page.
* **Content Body (Markdown Format):** Rich-text explanations, study instructions, embedded videos, or core theoretical materials required for the topic.

## 2. Penultimate Wizard Page (Assignment Step)
* **Functionality:** Dedicated interface elements for the student to input answers, complete an interactive test, or upload files containing their finished practical work.

## 3. Final Wizard Page (Submission & Review Step)
* **Feedback & Comments:** A designated block for final student comments and submission notes before sending the work for review.
* **Submission Trigger:** Actions to formally hand over the assignment to the tutor.
* **Help Trigger:** A dedicated query button ("Do you understand everything?" / Need Help) available if the student gets stuck or requires clarification.
